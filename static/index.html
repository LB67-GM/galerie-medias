Galerie Médias 3.0

Les photos peuvent rester sur un disque USB. La base (index, visages, miniatures) est enregistrée sur cet ordinateur, pas sur le USB. C’est plus fiable si vous débranchez le disque. Sous Windows, indiquez par exemple E:\Photos. Si la lettre change, double-cliquez sur lister-disques.bat, mettez à jour ce chemin, puis enregistrez.

iPhone : même Wi-Fi. À la maison : https://photos.example.com:8765. Premier passage : continuer vers le site si le navigateur le demande. Réglages iPhone → Confidentialité → Réseau local → autoriser Safari. Puis Partager → Sur l’écran d’accueil.

Téléphone

Le site reste sur cet ordinateur. Choisissez d’où viennent les photos à télécharger.

iCloud

Cette section sert uniquement à télécharger les photos et les vidéos encore stockées dans iCloud (Photothèque iCloud). Les fichiers arrivent dans le dossier de triage. Le classement par année et lieu se fait dans la section Classer, plus bas. Le bouton Exécuter le téléchargement ne lance que ce téléchargement : il n’enregistre pas le reste de la page.

Le dossier de triage est une zone d’arrivée, pas la galerie. Les photos y restent jusqu’au classement. Exemple après un téléchargement : 2024/06/IMG_1234.HEIC. Elles apparaissent dans Photos seulement après Classer, puis Indexer.

L’avancement s’affiche en bandeau en haut de la page, et dans le cadre en haut de Paramètres (nombre de fichiers reçus).

Code 2FA — Apple l’affiche sur l’iPhone ou l’iPad (notification). Saisissez-le ici, pas dans le terminal.

Google Photos

Google n’offre plus d’outil fiable du type iCloud pour tout télécharger automatiquement. Deux façons simples :

  1. Takeout — sur un ordinateur : takeout.google.com → Google Photos → exporter → décompresser le zip.
  2. Câble — branchez le téléphone, copiez le dossier DCIM (et éventuellement Pictures).

En mode Android, le téléchargement iCloud n’est pas utilisé. Le classement se fait dans la section Classer.

Facebook

Vous pouvez télécharger vos photos et vos vidéos depuis Facebook. Dans Facebook : Paramètres et confidentialité, puis Vos informations, puis Télécharger vos informations. Demandez les photos, les vidéos et les messages. Décompressez l’archive dans le dossier ci-dessous, enregistrez, puis Classer depuis Facebook. La date vient du fichier message_1.json, car ces médias n’ont souvent pas de date dans la photo.

Archive téléchargée :
  facebook/messages/inbox/Nom/photos/12345.jpg
  facebook/messages/inbox/Nom/message_1.json

Après le classement :
  Annee 2019/Mars 2019/12345.jpg
  Annee 2019/Montreal/12345.jpg    s’il y a une position
Classer

Cette section range les photos dans la bibliothèque. Le dossier de triage est une zone d’arrivée : ce n’est pas encore la galerie. Simuler n’écrit rien. Après un classement réel, cliquez Indexer. Les noms Annee et les mois en français (Juin, Juillet) sont les noms des dossiers sur le disque : ils ne changent pas avec la langue du site.

Dossier de triage, après un téléchargement :
  2024/06/IMG_1234.HEIC

Après « Classer année / mois » :
  Annee 2024/Juin 2024/IMG_1234.HEIC

Après « Classer la bibliothèque actuelle », s’il y a une position :
  Annee 2024/Rome/IMG_1234.HEIC

Sans position, le fichier reste dans Annee 2024/Juin 2024/.

Le classement depuis le triage utilise le dossier indiqué dans iCloud.

L’avancement s’affiche comme le téléchargement (bandeau et cadre Paramètres). « Classer la bibliothèque actuelle » ne touche pas au dossier de triage : villes GPS seulement. « Classer année / mois » range vers Annee/Mois (copie, ou déplacement si la source et la destination sont le même dossier). Ensuite, classez la bibliothèque pour les villes.

Sauvegarde

Copie la base (index, visages nommés), les réglages, et le site (pages HTML, CSS, JS, code Python, sans Python/.venv). Les miniatures se régénèrent avec Indexer. La destination peut être un disque USB ou un NAS. Les 4 plus récentes sont conservées. Sur l’ordinateur principal, un minuteur peut lancer cela le mercredi ; chez vous, cliquez sur le bouton.

Courriel

Un seul compte envoie les liens. Exemple Gmail : serveur smtp.gmail.com, port 587, identifiant et expéditeur john.doe@gmail.com, STARTTLS coché. Le mot de passe est un mot de passe d’application (16 lettres) : les espaces sont retirés. Ce n’est pas le courriel de chaque personne. L’adresse du site, par exemple https://photos.example.com:8765, est celle du lien.

Comptes

Sans compte, le site reste ouvert. Le premier compte est administrateur. Mot de passe : 8 caractères minimum. Trois essais, puis le compte est verrouillé. Le courriel est obligatoire : c’est la boîte de cette personne (exemple marie.martin@gmail.com), celle qu’elle écrit dans Mot de passe oublié. Le bouton Enregistrer à côté du compte la sauvegarde. Deux comptes ne partagent pas la même adresse. Un compte lecture voit les photos, la carte et les albums.

    Ce bouton enregistre les paramètres de cette page, y compris l’envoi des courriels. Il n’enregistre pas le courriel de chaque compte : ce courriel a son bouton Enregistrer, sur la même ligne. Il ne lance ni le téléchargement, ni le classement, ni la sauvegarde.

    Cochez seulement les visages que vous reconnaissez, puis nommez la sélection. Revoir puis Pas… retire une erreur. En grand format, la touche X retire le visage.
