The application

Galerie Médias is a site you run at home, on your computer. It shows the photos and videos from a folder on that machine, or on a network disk, without sending them elsewhere. You find them by year, month, place, moment, album, or first name. You view them large, as a slideshow, or on a television in the house. You can send a photo or a video to Facebook, Messenger, Instagram, or TikTok: the file goes to the app, and the site stays private. An administrator prepares the library, names people, sorts scenes, corrects a place, moves files, or sends them to Trash. A viewer account looks, without changing anything.

The server program is written in Python. The pages you see are written in HTML, CSS, and JavaScript. The list of photos is stored in SQLite, which comes with Python. The map uses Leaflet. Faces, scenes, and videos rely on other open programs, including OpenCV, InsightFace, ONNX Runtime, and FFmpeg.

Galerie Médias is published under the MIT licence (file LICENSE). You may copy, modify and redistribute this program, including in a paid product, as long as that file and the author’s name stay with it. The other components are listed in NOTICE.

The libraries installed with Python keep their own licence (MIT, BSD or Apache 2.0). The map uses Leaflet 1.9.4 (BSD). The flags come from flag-icons (MIT). City names come from GeoNames, under Creative Commons BY 4.0. Map tiles are © OpenStreetMap contributors.

Without those models, detection uses OpenCV (YuNet and SFace), under a permissive licence. FFmpeg, used for videos, is a separate program under the GPL. It is not included in the Galerie Médias sources.

Language and theme

Two menus stay at the top right.

  • Language: French, English, Spanish, or German. On the first visit, the site follows your browser. If it does not recognize that language, it stays in French.
  • Theme: Amber (dark, warm), Ink, Ocean, Forest, Paper (light), and Daylight (light). Amber is the original theme.

The choice stays in this browser, on this device. It does not change anyone else’s account.

HTTPS and the certificate

The site always opens with an address that starts with https://, on port 8765. There is no http:// address. The lock encrypts the exchange between your browser and the computer that runs the gallery. The photos stay on that computer. They are not published on the Internet.

Two locks are possible. The first one is enough at home.

  • Home certificate. Nothing to install. It is created on the first start. The browser shows a warning once, because this certificate is not known to the public. Continue to the site: it is your computer. On this computer, the address is https://127.0.0.1:8765. From a phone on the same Wi-Fi, it looks like https://192.168.x.x:8765.
  • Name certificate. Let’s Encrypt issues it for free. It is tied to a name, for example https://photos.example.com:8765. The browser no longer shows a warning. When it is installed, it replaces the home certificate. When it is missing, the home certificate stays in use. The tool that requests it is called Certbot: certbot.eff.org.

WireGuard is a VPN: a private tunnel between your phone, or another computer, and the house, when you are not on the Wi-Fi. Installers for Windows, macOS, Linux, iPhone, and Android are at wireguard.com/install. With the name certificate, the gallery answers on the home Wi-Fi and through this tunnel. It does not answer from a café without the tunnel. Do not open port 8765 on the router.

An LG or Samsung television uses another port, 8766, without a certificate. That is not the address of the site. The TV button uses it only on the home network.

Obtain the name certificate

This part is optional. It proves that the name belongs to you, without opening a port. The certificate follows the name: when you move, change the address of the name and keep the same certificate.

These three steps are the same on Linux, macOS, and Windows.

  1. Register a domain name at Cloudflare. Decline any paid offer for a certificate, hosting, or email. Let’s Encrypt is free.
  2. In the DNS for the name, add an A record. Name: @. Address: the computer that runs the gallery, on the home network (it often starts with 192.168). Click the Cloudflare cloud until it is grey. An orange cloud does not fit. Do not forward port 8765 to the Internet.
  3. Create a token on the Cloudflare token page, limited to this name, with permission to edit DNS. Do not copy it into a message, a document, or a chat. The file that holds it has one line: dns_cloudflare_api_token = THE_TOKEN

The command that requests the certificate depends on the system. Replace photos.example.com with your name. The expected ending is Successfully received certificate. Two files matter: fullchain.pem and privkey.pem. Copy the files themselves, not a shortcut.

Linux

On the Linux computer that runs the site:

sudo apt-get install certbot python3-certbot-dns-cloudflare

Save the token in /etc/letsencrypt/cloudflare.ini, readable only by the administrator (mode 600). Then:

sudo certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials /etc/letsencrypt/cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

Copy the two files into the gallery folder. Create it if it is missing. A gallery started with start-linux.sh reads them in ~/.config/galerie-photos/cache/letsencrypt/. A service whose cache is ~/.cache/photo-library/ reads them in ~/.cache/photo-library/letsencrypt/.

mkdir -p ~/.config/galerie-photos/cache/letsencrypt
sudo cp -L /etc/letsencrypt/live/photos.example.com/fullchain.pem ~/.config/galerie-photos/cache/letsencrypt/
sudo cp -L /etc/letsencrypt/live/photos.example.com/privkey.pem ~/.config/galerie-photos/cache/letsencrypt/

About every sixty days, run the same Certbot command and copy the two files again.

macOS

The Linux command does not run as-is in the Mac Terminal. Install Homebrew, then Certbot and the Cloudflare module:

brew install certbot
"$(brew --prefix certbot)/libexec/bin/python3" -m pip install certbot-dns-cloudflare

Create the folder ~/.secrets/certbot/ and the file cloudflare.ini with the token line. In Terminal: chmod 600 ~/.secrets/certbot/cloudflare.ini. Then:

sudo certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials ~/.secrets/certbot/cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

The files arrive in /etc/letsencrypt/live/photos.example.com/. Copy them to the gallery folder. Create that folder if it does not exist:

mkdir -p "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt"
sudo cp -L /etc/letsencrypt/live/photos.example.com/fullchain.pem "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt/"
sudo cp -L /etc/letsencrypt/live/photos.example.com/privkey.pem "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt/"

Close the gallery window and open start-mac.command again. The certificate lasts about sixty days. Run the Certbot command again, then copy the two files again. The script that renews by itself is for Linux only.

Windows

The Linux command does not work in the gallery’s black window, nor in the command prompt, until Certbot is installed for Windows.

The simplest way, if a Linux computer at home already has the certificate: copy fullchain.pem and privkey.pem into

C:\Users\YOURNAME\AppData\Roaming\GaleriePhotos\cache\letsencrypt\

Create the letsencrypt folder if it does not exist. Close the black window, then open the gallery again.

If the gallery runs only on Windows, install Python from python.org/downloads and tick “Add python.exe to PATH”. Open PowerShell, then:

py -m pip install certbot certbot-dns-cloudflare

Create a file, for example C:\Users\YOURNAME\secrets\cloudflare.ini, with the token line. Then, in PowerShell:

py -m certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials C:\Users\YOURNAME\secrets\cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

Certbot names the folder at the end. It contains the two files. On Windows, that folder is often C:\Certbot\live\photos.example.com\. Copy fullchain.pem and privkey.pem into C:\Users\YOURNAME\AppData\Roaming\GaleriePhotos\cache\letsencrypt\, then open the gallery again. About every sixty days, run the same Certbot command and copy the two files again.

Then open https://photos.example.com:8765. The lock matches the name. The port stays 8765.

Installing the program on Linux, macOS, and Windows is described separately: Installation.

Sign in

Until an account exists, the gallery is open. As soon as one account is created, the sign-in page appears.

  1. Enter your username.
  2. Enter your password.
  3. Choose Sign in.

This browser then recognizes you for 14 days. You do not have to type the password again on each visit, on this same device. Log out removes access: photos stay hidden until you sign in again.

Three wrong attempts lock the account. Use Forgot password, or ask an administrator to reset it.

The first account is an administrator. A viewer account can see photos, the map, albums, and this help. It cannot change the library or the accounts.

Forgot password

On the sign-in page, choose Forgot password.

  1. Enter the account email.
  2. Choose Send link.
  3. Open the message. The link is valid for one hour.
  4. Choose a new password, at least 8 characters, and confirm it.

The site does not say whether the email exists. If it matches an account, the link is sent. After you save it, older sessions for that account are closed: you need to sign in again.

The email entered here is the account email, under Accounts. It is not necessarily the address that sends the messages. If email is not set up yet, the site says so. An administrator prepares it in Settings, under Email, and enters each account’s email under Accounts. Without that, only an administrator can set a new password.

Photos

This is the home page. With no filter, the newest photos appear first.

Filters

On a phone, open Filters. Filters combine: a year and a place and an album, for example.

  • Year and Month: from the folder or the photo’s date.
  • Place: a city, region, or country. Moment: a trip, a birthday, a party. A trip is not a place.
  • Type: photos or videos.
  • Album and Scene: see below.
  • Search: a whole word in the file name, place, moment, or first name. “Rome” does not find “Andromeda”. The cross in the field brings back the whole gallery. There is no People menu here: type the first name in search.

Changing a filter clears the current selection.

View a photo

Click a thumbnail to open it large. The frame keeps the proportions. Pinch the screen, or use the wheel, to zoom. Previous and Next move to the neighboring photo. Slideshow plays them in order.

Videos play in the browser, including those from an iPhone.

Share sends the photo or video to Facebook, Messenger, Instagram, or TikTok. The file goes to the app: these networks do not read the site. On a computer without a share list, the file downloads; then open the app and choose it.

Television

TV sends the photo or video to an LG or Samsung TV that is on, on the same network. Choose the TV’s name, then stop it from the same window when you are done.

Selection

These actions are for the administrator, except the slideshow, the TV, and sharing.

  • This page checks the visible photos. Select all checks the whole filter, not only this page. Shift-click selects a range. Clear selection removes the checks.
  • The star adds the photo to an album, or removes it.
  • Add to album and Remove from album need at least one checked photo.
  • Place corrects the displayed name and the pin on the map. The folder on disk does not change. Drag the map: the pin stays in the center. You can also correct the other photos in that folder only.
  • Move sends the checked files to a folder that already exists, in the same year. A video with the same name goes with them.
  • Export copies the originals: the file explorer asks for the folder. A zip archive can be downloaded instead. The window closes when it is done. The library files stay where they are.
  • Delete sends the selection to Trash for 30 days, after you confirm. The limit is 500 files at a time.

In the large view, Rotate / crop keeps the edited photo in the gallery and puts the original in Trash. Restore, in Trash, brings the original back.

People

Administrators only. Recognition stays on this computer: no face is sent anywhere else.

  1. Choose Index in Tools, so the photos are known.
  2. Choose Find people. The first time can take a while.
  3. Check only the faces you recognize, then name the selection.
  4. Review brings a photo of that person to the top. Not… removes a mistake.

In the large view, the X key removes the face. For new photos: index first, then detect again. Only files that have not been analyzed yet are processed.

Scenes

Administrators only. A scene is a tag: church, mountain, city, range…

  1. Choose a year, and a place if you want a smaller set.
  2. Choose Find scenes. The result is a suggestion, and often needs correction.
  3. Check only the right photos, then tag the selection.
  4. Review, then Not…, removes a mistake.

In Photos, the Scene filter finds those photos later.

Duplicates

Administrators only. The same photo can exist as several files. Keep is a suggestion, not a requirement.

You can trash every extra copy, or only the ones you check. A confirmation appears. The files stay in Trash for 30 days.

Map

Each marker is a place. Click it to open the photos of that place. Trips, birthdays, and parties live in the Moment filter, not on the map.

Map tiles come from the Internet (© OpenStreetMap contributors). Without a network, the map does not appear; the photos themselves remain available.

A place you corrected in Place stays in the Place menu.

Albums

An album is a list. Files are not copied: a photo can be in several albums. Favorites is an album like the others.

  1. Type a name, then create the album.
  2. Open it, or go back to Photos.
  3. Check photos, then Add to album. The star does the same thing, and can also remove the photo.

In an open album, Remove from album takes the selection out of that album. The file stays in the library.

Trash

Administrators only. Deleted photos stay here for 30 days. After that, the site removes them.

  • Restore selection puts the files back.
  • Delete permanently applies only to the checked files, after you confirm. This cannot be undone.

This page, All, and Clear selection work as they do in Photos.

Settings

Administrators only. Save, at the bottom of the page, stores the settings. It does not download, organize, or back up.

Phone

The site stays on the computer that runs it. On the phone, use the same Wi-Fi, open the site address, then accept the certificate if the browser asks. You can then add it to the home screen.

Choose where the photos come from: iPhone / iCloud, Android / Google Photos, or a Facebook / Messenger archive.

iCloud

This section downloads photos and videos still in iCloud into the intake folder. Enter the Apple ID, the password, and, if you want, the year and month. The password stays encrypted on this computer. The code Apple asks for appears on the iPhone: type it on this page, not in another window.

Before the first download, sign in at icloud.com with the same Apple ID, in a browser. Apple sometimes shows its terms and conditions before opening the photos. Until those terms are accepted, the download cannot fetch the photos.

The intake folder is an arrival area. It is not the gallery. Files stay there until you organize them, then click Index. Example after an iCloud download:

triage/2024/06/IMG_1234.HEIC

Google Photos

Two simple ways: export from Google Takeout, or plug in the phone and copy the DCIM folder. Then point to that folder. Organizing is done under Organize.

Facebook

You can download photos and videos from Facebook. In Facebook: Settings and privacy, then Your information, then Download your information. Request the photos, the videos, and the messages. The file message_1.json holds the date, because these files often have no date inside the photo itself. Unpack the archive into the folder you set, save, then run Organize from Facebook.

facebook/messages/inbox/Name/photos/12345.jpg
facebook/messages/inbox/Name/message_1.json

After organizing, a file dated March 2019 is stored like this. When a location is present, the city replaces the month:

Annee 2019/Mars 2019/12345.jpg
Annee 2019/Montreal/12345.jpg

Organize

Organizing copies files into the library. When the source and the destination are the same folder, it moves them. Run the simulation first: it writes nothing. Then click Index to see the photos.

Organize year / month sorts by date. A photo taken in June 2024, still in the intake folder, becomes:

Annee 2024/Juin 2024/IMG_1234.HEIC

Organize from intake reads the intake folder (iCloud) or the Takeout / DCIM folder. Organize the current library does not read the intake folder. It sorts photos already in the library, at the root of a year or in a month folder, into a city folder when a location is present:

Annee 2024/Rome/IMG_1234.HEIC

Without a location, the file stays in the month folder, for example Annee 2024/Juin 2024/. The name Annee and the French month names are the folder names on disk. They do not change with the site language.

Backup

Choose a folder (an external disk, another computer), then Back up now. The copy contains the index, the settings, and the site pages. Thumbnails are not copied: Index rebuilds them. The photos themselves stay where they are.

Email

This section sets the account that sends the “forgot password” link. It is not each person’s email. One account is enough for the whole household.

Example with Gmail:

  • Server: smtp.gmail.com
  • Port: 587
  • Username: john.doe@gmail.com
  • Password: a Google app password, 16 letters. Google shows them as four blocks separated by spaces. Spaces do not count: the site removes them. This is not the usual Google account password.
  • From: john.doe@gmail.com, the same account as the username. An invented address, for example galerie@gmail.com, is not sent.
  • STARTTLS encryption: on.
  • Site address: https://photos.example.com:8765, as people open it in the browser.

The app password is created at https://myaccount.google.com/apppasswords, after 2-Step Verification. Choose “Other” and the name Gallery. It stays encrypted on this computer. Leave the field empty to keep the one already stored.

Save, at the bottom of the page, stores this section. It does not store account emails.

Accounts

Each person has their own email. It is the address that receives the link, and the address they type in Forgot password. It can differ from the Gmail account that sends.

John Doe uses john.doe@gmail.com to send. His gallery account uses that same address only if it really is his mailbox. Marie Martin has another account: her email is marie.martin@gmail.com. Marie’s link arrives in Marie’s mailbox. Two accounts cannot share the same address.

When you create an account, the email is required. After a change, the Save button on the same line as the account shows “Email saved.” Reload the page: the address must still be there. The button at the bottom of the page does not save it. The browser’s autofill can show an address that is not saved.

Also create a username, a password of at least 8 characters, and a role. You can remove an account.

Tools

Administrators only. The Tools button opens three actions.

  • Index reads the library and prepares thumbnails. Choose a year, or the whole library. Do this before finding people or scenes, and after new photos arrive.
  • Find people: see People.
  • Find scenes: see Scenes.

Progress appears in the bar at the top of the page. Wait until it finishes before starting another one.

Viewer account

With a viewer account, you see Photos, Map, Albums, and ?. You can filter, open photos, start the slideshow, send to the TV, and share a photo or a video.

You do not see People, Scenes, Duplicates, Trash, Settings, or Tools. You cannot delete, move, export, or edit a place.
