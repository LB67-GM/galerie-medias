Die Anwendung

Galerie Médias ist eine Website, die Sie zu Hause auf Ihrem Computer betreiben. Sie zeigt die Fotos und Videos eines Ordners auf diesem Gerät oder auf einem Netzlaufwerk, ohne sie woandershin zu senden. Sie finden sie nach Jahr, Monat, Ort, Moment, Album oder Vornamen. Sie sehen sie groß, als Diashow oder auf einem Fernseher im Haus. Sie können ein Foto oder ein Video an Facebook, Messenger, Instagram oder TikTok senden: die Datei geht an die App, und die Website bleibt privat. Eine Verwaltung bereitet die Bibliothek vor, benennt Personen, ordnet Szenen, korrigiert einen Ort, verschiebt Dateien oder legt sie in den Papierkorb. Ein Lesekonto schaut zu, ohne etwas zu ändern.

Das Programm des Servers ist in Python geschrieben. Die Seiten, die Sie sehen, sind in HTML, CSS und JavaScript geschrieben. Die Fotoliste liegt in SQLite, das zu Python gehört. Die Karte nutzt Leaflet. Gesichter, Szenen und Videos stützen sich auf weitere offene Programme, insbesondere OpenCV, InsightFace, ONNX Runtime und FFmpeg.

Galerie Médias steht unter der MIT-Lizenz (Datei LICENSE). Sie dürfen dieses Programm kopieren, ändern und weitergeben, auch in einem kostenpflichtigen Produkt, wenn diese Datei und der Name des Urhebers dabei bleiben. Die übrigen Bestandteile stehen in NOTICE.

Die mit Python installierten Bibliotheken behalten ihre Lizenz (MIT, BSD oder Apache 2.0). Die Karte nutzt Leaflet 1.9.4 (BSD). Die Flaggen stammen von flag-icons (MIT). Die Städtenamen stammen von GeoNames, unter Creative Commons BY 4.0. Die Kartenkacheln sind © OpenStreetMap contributors.

Die Gesichtemodelle von InsightFace (buffalo_l), geladen nach ~/.insightface/, stehen nicht unter MIT. InsightFace behält sie der nicht-kommerziellen Forschung vor. Ohne diese Modelle nutzt die Erkennung OpenCV (YuNet und SFace), unter einer freizügigen Lizenz. FFmpeg, für die Videos, ist ein separates Programm unter der GPL. Es ist nicht in den Quellen von Galerie Médias enthalten.

Sprache und Thema

Oben rechts bleiben zwei Menüs sichtbar.

  • Sprache: Französisch, Englisch, Spanisch oder Deutsch. Beim ersten Besuch folgt die Seite der Sprache Ihres Browsers. Erkennt sie diese nicht, bleibt sie auf Französisch.
  • Thema: Bernstein (dunkel, warm), Tinte, Ozean, Wald, Papier (hell) und Tag (hell). Bernstein ist das ursprüngliche Thema.

Die Wahl bleibt in diesem Browser, auf diesem Gerät. Sie ändert nicht das Konto anderer Personen.

HTTPS und das Zertifikat

Die Seite öffnet sich immer mit einer Adresse, die mit https:// beginnt, auf Port 8765. Es gibt keine Adresse mit http://. Das Schloss verschlüsselt den Austausch zwischen Ihrem Browser und dem Computer, auf dem die Galerie läuft. Die Fotos bleiben auf diesem Computer. Sie werden nicht im Internet veröffentlicht.

Zwei Schlösser sind möglich. Das erste genügt zu Hause.

  • Haus-Zertifikat. Nichts zu installieren. Es entsteht beim ersten Start. Der Browser zeigt einmal eine Warnung, weil dieses Zertifikat öffentlich nicht bekannt ist. Gehen Sie weiter zur Seite: es ist Ihr Computer. Auf diesem Computer lautet die Adresse https://127.0.0.1:8765. Vom Telefon im selben WLAN ähnelt sie https://192.168.x.x:8765.
  • Zertifikat eines Namens. Let’s Encrypt stellt es kostenlos aus. Es hängt an einem Namen, zum Beispiel https://photos.example.com:8765. Der Browser zeigt keine Warnung mehr. Wenn es installiert ist, ersetzt es das Haus-Zertifikat. Wenn es fehlt, bleibt das Haus-Zertifikat in Betrieb. Das Werkzeug, das es anfordert, heißt Certbot: certbot.eff.org.

WireGuard ist ein VPN: ein privater Tunnel zwischen Ihrem Telefon oder einem anderen Computer und dem Haus, wenn Sie nicht im WLAN sind. Die Installationsprogramme für Windows, macOS, Linux, iPhone und Android stehen auf wireguard.com/install. Mit dem Namenszertifikat antwortet die Galerie im Haus-WLAN und durch diesen Tunnel. Sie antwortet nicht aus einem Café ohne den Tunnel. Öffnen Sie Port 8765 nicht an der Box.

Ein Fernseher von LG oder Samsung nutzt einen anderen Port, 8766, ohne Zertifikat. Das ist nicht die Adresse der Seite. Die Schaltfläche TV verwendet ihn nur im Hausnetz.

Das Zertifikat des Namens erhalten

Dieser Teil ist freiwillig. Er beweist, dass der Name Ihnen gehört, ohne einen Port zu öffnen. Das Zertifikat folgt dem Namen: beim Umzug ändern Sie die Adresse des Namens und behalten dasselbe Zertifikat.

Diese drei Schritte sind unter Linux, macOS und Windows dieselben.

  1. Reservieren Sie einen Domainnamen bei Cloudflare. Lassen Sie jedes kostenpflichtige Angebot für Zertifikat, Hosting oder E-Mail weg. Let’s Encrypt ist kostenlos.
  2. Tragen Sie im DNS des Namens einen A-Eintrag ein. Name: @. Adresse: der Computer, auf dem die Galerie läuft, im Hausnetz (sie beginnt oft mit 192.168). Klicken Sie die Cloudflare-Wolke, bis sie grau ist. Eine orange Wolke passt nicht. Leiten Sie Port 8765 nicht ins Internet weiter.
  3. Erstellen Sie ein Token auf der Cloudflare-Token-Seite, beschränkt auf diesen Namen, mit dem Recht, das DNS zu ändern. Kopieren Sie es nicht in eine Nachricht, ein Dokument oder einen Chat. Die Datei, die es enthält, hat eine Zeile: dns_cloudflare_api_token = DAS_TOKEN

Der Befehl, der das Zertifikat anfordert, hängt vom System ab. Ersetzen Sie photos.example.com durch Ihren Namen. Das erwartete Ende ist Successfully received certificate. Zwei Dateien zählen: fullchain.pem und privkey.pem. Kopieren Sie die Dateien selbst, keine Verknüpfung.

Linux

Auf dem Linux-Computer, der die Seite betreibt:

sudo apt-get install certbot python3-certbot-dns-cloudflare

Speichern Sie das Token in /etc/letsencrypt/cloudflare.ini, lesbar nur für den Administrator (Rechte 600). Dann:

sudo certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials /etc/letsencrypt/cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

Kopieren Sie die beiden Dateien in den Ordner der Galerie. Legen Sie ihn an, wenn er fehlt. Eine mit start-linux.sh gestartete Galerie liest sie in ~/.config/galerie-photos/cache/letsencrypt/. Ein Dienst, dessen Cache in ~/.cache/photo-library/ liegt, liest sie in ~/.cache/photo-library/letsencrypt/.

mkdir -p ~/.config/galerie-photos/cache/letsencrypt
sudo cp -L /etc/letsencrypt/live/photos.example.com/fullchain.pem ~/.config/galerie-photos/cache/letsencrypt/
sudo cp -L /etc/letsencrypt/live/photos.example.com/privkey.pem ~/.config/galerie-photos/cache/letsencrypt/

Etwa alle sechzig Tage starten Sie denselben Certbot-Befehl und kopieren die beiden Dateien wieder.

macOS

Der Linux-Befehl läuft nicht unverändert im Terminal des Mac. Installieren Sie Homebrew, dann Certbot und das Cloudflare-Modul:

brew install certbot
"$(brew --prefix certbot)/libexec/bin/python3" -m pip install certbot-dns-cloudflare

Legen Sie den Ordner ~/.secrets/certbot/ und die Datei cloudflare.ini mit der Token-Zeile an. Im Terminal: chmod 600 ~/.secrets/certbot/cloudflare.ini. Dann:

sudo certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials ~/.secrets/certbot/cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

Die Dateien liegen in /etc/letsencrypt/live/photos.example.com/. Kopieren Sie sie in den Ordner der Galerie. Legen Sie diesen Ordner an, wenn er fehlt:

mkdir -p "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt"
sudo cp -L /etc/letsencrypt/live/photos.example.com/fullchain.pem "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt/"
sudo cp -L /etc/letsencrypt/live/photos.example.com/privkey.pem "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt/"

Schließen Sie das Fenster der Galerie und öffnen Sie start-mac.command erneut. Das Zertifikat gilt etwa sechzig Tage. Starten Sie den Certbot-Befehl erneut und kopieren Sie die beiden Dateien wieder. Das Skript, das von selbst erneuert, gibt es nur für Linux.

Windows

Der Linux-Befehl funktioniert weder im schwarzen Fenster der Galerie noch in der Eingabeaufforderung, solange Certbot nicht für Windows installiert ist.

Am einfachsten, wenn ein Linux-Computer im Haus das Zertifikat schon hat: kopieren Sie fullchain.pem und privkey.pem nach

C:\Users\IHRNAME\AppData\Roaming\GaleriePhotos\cache\letsencrypt\

Legen Sie den Ordner letsencrypt an, wenn er fehlt. Schließen Sie das schwarze Fenster und öffnen Sie die Galerie erneut.

Wenn die Galerie nur unter Windows läuft, installieren Sie Python von python.org/downloads und setzen Sie das Häkchen „Add python.exe to PATH“. Öffnen Sie PowerShell und dann:

py -m pip install certbot certbot-dns-cloudflare

Legen Sie eine Datei an, zum Beispiel C:\Users\IHRNAME\secrets\cloudflare.ini, mit der Token-Zeile. Dann in PowerShell:

py -m certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials C:\Users\IHRNAME\secrets\cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

Certbot nennt den Ordner am Ende. Er enthält die beiden Dateien. Unter Windows ist dieser Ordner oft C:\Certbot\live\photos.example.com\. Kopieren Sie fullchain.pem und privkey.pem nach C:\Users\IHRNAME\AppData\Roaming\GaleriePhotos\cache\letsencrypt\ und öffnen Sie die Galerie erneut. Etwa alle sechzig Tage starten Sie denselben Certbot-Befehl und kopieren die beiden Dateien wieder.

Öffnen Sie danach https://photos.example.com:8765. Das Schloss passt zum Namen. Der Port bleibt 8765.

Die Installation des Programms unter Linux, macOS und Windows steht gesondert: Installation.

Anmeldung

Solange kein Konto besteht, ist die Galerie offen. Sobald ein Konto angelegt ist, erscheint die Anmeldeseite.

  1. Geben Sie Ihren Benutzernamen ein.
  2. Geben Sie Ihr Passwort ein.
  3. Wählen Sie Anmelden.

Dieser Browser erkennt Sie danach 14 Tage lang. Sie müssen das Passwort nicht bei jedem Besuch erneut eingeben, auf demselben Gerät. Abmelden entzieht den Zugang: die Fotos bleiben verborgen, bis Sie sich wieder anmelden.

Drei falsche Versuche sperren das Konto. Nutzen Sie dann Passwort vergessen, oder bitten Sie eine Verwaltung, es zurückzusetzen.

Das erste Konto ist ein Administratorkonto. Ein Konto mit Leserecht sieht Fotos, Karte, Alben und diese Hilfe. Es ändert weder die Bibliothek noch die Konten.

Passwort vergessen

Wählen Sie auf der Anmeldeseite Passwort vergessen.

  1. Geben Sie die E-Mail des Kontos ein.
  2. Wählen Sie Link senden.
  3. Öffnen Sie die Nachricht. Der Link gilt eine Stunde.
  4. Wählen Sie ein neues Passwort, mindestens 8 Zeichen, und bestätigen Sie es.

Die Seite sagt nicht, ob die E-Mail existiert. Wenn sie zu einem Konto gehört, wird der Link gesendet. Nach dem Speichern werden ältere Sitzungen dieses Kontos geschlossen: Sie müssen sich neu anmelden.

Die hier eingegebene E-Mail ist die des Kontos, unter Konten. Sie ist nicht unbedingt die Adresse, die Nachrichten sendet. Wenn die E-Mail noch nicht eingerichtet ist, sagt die Seite das. Eine Verwaltung richtet sie unter Einstellungen, Abschnitt E-Mail, ein und trägt die E-Mail jedes Kontos unter Konten ein. Ohne das kann nur eine Verwaltung ein neues Passwort setzen.

Fotos

Das ist die Startseite. Ohne Filter erscheinen die neuesten Fotos zuerst.

Filter

Öffnen Sie auf einem Telefon Filter. Filter lassen sich kombinieren: ein Jahr und ein Ort und ein Album, zum Beispiel.

  • Jahr und Monat: nach dem Ordner oder dem Datum des Fotos.
  • Ort: eine Stadt, eine Region, ein Land. Moment: eine Reise, ein Geburtstag, ein Fest. Eine Reise ist kein Ort.
  • Typ: Fotos oder Videos.
  • Album und Szene: siehe unten.
  • Suche: ein ganzes Wort im Dateinamen, im Ort, im Moment oder im Vornamen. „Rom“ findet nicht „Andromeda“. Das Kreuz im Feld bringt die ganze Galerie zurück. Hier gibt es kein Menü Personen: tippen Sie den Vornamen in die Suche.

Ein anderer Filter löscht die aktuelle Auswahl.

Ein Foto ansehen

Klicken Sie auf eine Miniatur, um sie groß zu öffnen. Der Rahmen behält die Proportionen. Ziehen Sie die Finger zusammen, oder nutzen Sie das Rad, um zu vergrößern. Zurück und Weiter gehen zum benachbarten Foto. Diashow spielt sie der Reihe nach ab.

Videos laufen im Browser, auch die vom iPhone.

Teilen sendet das Foto oder das Video an Facebook, Messenger, Instagram oder TikTok. Die Datei geht an die App: diese Netzwerke lesen die Website nicht. Auf einem Computer ohne Teilen-Liste wird die Datei heruntergeladen; öffnen Sie danach die App und wählen Sie sie aus.

Fernseher

TV sendet das Foto oder das Video an einen eingeschalteten Fernseher von LG oder Samsung, im selben Netzwerk. Wählen Sie den Namen des Fernsehers und beenden Sie die Wiedergabe im selben Fenster, wenn Sie fertig sind.

Auswahl

Diese Aktionen sind der Verwaltung vorbehalten, außer Diashow, Fernseher und Teilen.

  • Diese Seite markiert die sichtbaren Fotos. Alle auswählen markiert den ganzen Filter, nicht nur diese Seite. Umschalt+Klick wählt einen Bereich. Auswahl aufheben entfernt die Markierungen.
  • Der Stern nimmt das Foto in ein Album auf oder entfernt es daraus.
  • Zum Album hinzufügen und Aus Album entfernen brauchen mindestens ein markiertes Foto.
  • Ort korrigiert den angezeigten Namen und die Markierung auf der Karte. Der Ordner auf der Festplatte ändert sich nicht. Ziehen Sie die Karte: die Markierung bleibt in der Mitte. Sie können auch die anderen Fotos nur dieses Ordners korrigieren.
  • Verschieben schickt die markierten Dateien in einen Ordner, der schon besteht, im selben Jahr. Das Video mit demselben Namen geht mit.
  • Exportieren kopiert die Originale: der Dateimanager fragt nach dem Ordner. Ein Zip-Archiv ist ebenfalls möglich. Das Fenster schließt sich am Ende. Die Dateien der Bibliothek bleiben an ihrem Platz.
  • Löschen legt die Auswahl nach der Bestätigung für 30 Tage in den Papierkorb. Die Grenze liegt bei 500 Dateien auf einmal.

In der großen Ansicht behält Drehen / zuschneiden das bearbeitete Foto in der Galerie und legt das Original in den Papierkorb. Wiederherstellen im Papierkorb bringt das Original zurück.

Personen

Nur für die Verwaltung. Die Erkennung bleibt auf diesem Computer: kein Gesicht wird woandershin gesendet.

  1. Wählen Sie Indexieren unter Werkzeuge, damit die Fotos bekannt sind.
  2. Wählen Sie Personen erkennen. Das erste Mal kann dauern.
  3. Markieren Sie nur Gesichter, die Sie erkennen, und benennen Sie die Auswahl.
  4. Prüfen holt ein Foto dieser Person nach oben. Nicht… entfernt einen Fehler.

In der großen Ansicht entfernt die Taste X das Gesicht. Bei neuen Fotos: zuerst indexieren, dann erneut erkennen. Nur Dateien, die noch nicht untersucht wurden, werden bearbeitet.

Szenen

Nur für die Verwaltung. Eine Szene ist eine Bezeichnung: Kirche, Berg, Stadt, Bereich…

  1. Wählen Sie ein Jahr, und einen Ort, wenn Sie die Menge begrenzen wollen.
  2. Wählen Sie Szenen erkennen. Das Ergebnis ist ein Vorschlag und oft zu korrigieren.
  3. Markieren Sie nur die richtigen Fotos und bezeichnen Sie die Auswahl.
  4. Prüfen, dann Nicht…, entfernt einen Fehler.

Unter Fotos findet der Filter Szene diese Fotos danach wieder.

Duplikate

Nur für die Verwaltung. Dasselbe Foto kann in mehreren Dateien vorliegen. Behalten ist ein Vorschlag, keine Pflicht.

Sie können alle überzähligen Kopien in den Papierkorb legen, oder nur die, die Sie markieren. Eine Bestätigung erscheint. Die Dateien bleiben 30 Tage im Papierkorb.

Karte

Jede Markierung ist ein Ort. Klicken Sie darauf, um die Fotos dieses Ortes zu öffnen. Reisen, Geburtstage und Feste stehen im Filter Moment, nicht auf der Karte.

Die Kartenhintergründe kommen aus dem Internet (© OpenStreetMap contributors). Ohne Netz erscheint die Karte nicht; die Fotos selbst bleiben verfügbar.

Ein Ort, den Sie unter Ort korrigiert haben, bleibt im Menü Ort.

Alben

Ein Album ist eine Liste. Dateien werden nicht kopiert: ein Foto kann in mehreren Alben sein. Favoriten ist ein Album wie die anderen.

  1. Geben Sie einen Namen ein und legen Sie das Album an.
  2. Öffnen Sie es, oder gehen Sie zurück zu Fotos.
  3. Markieren Sie Fotos und wählen Sie Zum Album hinzufügen. Der Stern tut dasselbe und kann das Foto auch entfernen.

In einem geöffneten Album nimmt Aus Album entfernen die Auswahl aus diesem Album. Die Datei bleibt in der Bibliothek.

Papierkorb

Nur für die Verwaltung. Gelöschte Fotos bleiben hier 30 Tage. Danach entfernt die Seite sie.

  • Auswahl wiederherstellen legt die Dateien zurück.
  • Endgültig löschen betrifft nur die markierten Dateien, nach der Bestätigung. Das lässt sich nicht rückgängig machen.

Diese Seite, Alle und Auswahl aufheben funktionieren wie unter Fotos.

Einstellungen

Nur für die Verwaltung. Speichern unten auf der Seite merkt sich die Einstellungen. Es startet weder den Download, noch das Sortieren, noch die Sicherung.

Telefon

Die Seite bleibt auf dem Computer, der sie betreibt. Nutzen Sie auf dem Telefon dasselbe WLAN, öffnen Sie die Adresse der Seite und akzeptieren Sie das Zertifikat, wenn der Browser danach fragt. Danach können Sie sie zum Startbildschirm hinzufügen.

Wählen Sie, woher die Fotos kommen: iPhone / iCloud, Android / Google Photos oder ein Archiv von Facebook / Messenger.

iCloud

Dieser Abschnitt lädt Fotos und Videos, die noch in iCloud liegen, in den Eingangsordner. Geben Sie die Apple-ID, das Passwort und bei Bedarf Jahr und Monat an. Das Passwort bleibt auf diesem Computer verschlüsselt. Der Code, den Apple verlangt, erscheint auf dem iPhone: geben Sie ihn auf dieser Seite ein, nicht in einem anderen Fenster.

Melden Sie sich vor dem ersten Download in einem Browser bei icloud.com an, mit derselben Apple-ID. Apple zeigt manchmal seine Nutzungsbedingungen, bevor die Fotos zugänglich sind. Solange sie nicht akzeptiert sind, kann der Download die Fotos nicht holen.

Der Eingangsordner ist ein Ankunftsbereich. Er ist nicht die Galerie. Die Dateien bleiben dort bis zum Sortieren und bis Indexieren. Beispiel nach einem iCloud-Download:

triage/2024/06/IMG_1234.HEIC

Google Photos

Zwei einfache Wege: aus Google Takeout exportieren, oder das Telefon anschließen und den Ordner DCIM kopieren. Geben Sie danach diesen Ordner an. Das Sortieren geschieht im Abschnitt Sortieren.

Facebook

Sie können Fotos und Videos von Facebook herunterladen. In Facebook: Einstellungen und Datenschutz, dann Deine Informationen, dann Informationen herunterladen. Fordern Sie die Fotos, die Videos und die Nachrichten an. Die Datei message_1.json enthält das Datum, denn diese Medien haben oft kein Datum im Foto selbst. Entpacken Sie das Archiv in den angegebenen Ordner, speichern Sie, und starten Sie dann Aus Facebook sortieren.

facebook/messages/inbox/Name/photos/12345.jpg
facebook/messages/inbox/Name/message_1.json

Nach dem Sortieren liegt eine Datei vom März 2019 so. Wenn eine Position vorhanden ist, ersetzt die Stadt den Monat:

Annee 2019/Mars 2019/12345.jpg
Annee 2019/Montreal/12345.jpg

Sortieren

Das Sortieren kopiert die Dateien in die Bibliothek. Wenn Quelle und Ziel derselbe Ordner sind, werden sie verschoben. Starten Sie zuerst die Simulation: sie schreibt nichts. Klicken Sie danach auf Indexieren, um die Fotos zu sehen.

Jahr / Monat sortieren ordnet nach Datum. Ein Foto vom Juni 2024, noch im Eingang, wird zu:

Annee 2024/Juin 2024/IMG_1234.HEIC

Aus dem Eingang sortieren liest den Eingangsordner (iCloud) oder den Ordner Takeout / DCIM. Aktuelle Bibliothek sortieren liest den Eingang nicht. Es ordnet Fotos, die schon in der Bibliothek sind, im Jahr oder in einem Monatsordner, in einen Stadtordner, wenn eine Position vorhanden ist:

Annee 2024/Rome/IMG_1234.HEIC

Ohne Position bleibt die Datei im Monatsordner, zum Beispiel Annee 2024/Juin 2024/. Der Name Annee und die französischen Monatsnamen sind die Ordnernamen auf der Festplatte. Sie ändern sich nicht mit der Sprache der Seite.

Sicherung

Geben Sie einen Ordner an (externe Festplatte, anderer Computer) und wählen Sie Jetzt sichern. Die Kopie enthält den Index, die Einstellungen und die Seiten der Site. Miniaturen werden nicht kopiert: Indexieren erstellt sie neu. Die Fotos selbst bleiben, wo sie sind.

E-Mail

Dieser Abschnitt stellt das Konto ein, das den Link „Passwort vergessen“ sendet. Das ist nicht die E-Mail jeder Person. Ein Konto genügt für das ganze Haus.

Beispiel mit Gmail:

  • Server: smtp.gmail.com
  • Port: 587
  • Benutzername: john.doe@gmail.com
  • Passwort: ein Google-App-Passwort, 16 Buchstaben. Google zeigt sie in vier Blöcken, getrennt durch Leerzeichen. Die Leerzeichen zählen nicht: die Seite entfernt sie. Das ist nicht das übliche Passwort des Google-Kontos.
  • Absender: john.doe@gmail.com, dasselbe Konto wie der Benutzername. Eine erfundene Adresse, zum Beispiel galerie@gmail.com, wird nicht gesendet.
  • STARTTLS-Verschlüsselung: an.
  • Adresse der Seite: https://photos.example.com:8765, so wie Personen sie im Browser öffnen.

Das App-Passwort wird unter https://myaccount.google.com/apppasswords erstellt, nach der Bestätigung in zwei Schritten. Wählen Sie „Andere“ und den Namen Galerie. Es bleibt auf diesem Computer verschlüsselt. Lassen Sie das Feld leer, um das bereits gespeicherte zu behalten.

Speichern unten auf der Seite speichert diesen Abschnitt. Es speichert nicht die E-Mail der Konten.

Konten

Jede Person hat ihre eigene E-Mail. Das ist die Adresse, die den Link erhält, und die Adresse, die sie bei Passwort vergessen eingibt. Sie kann sich vom Gmail-Konto unterscheiden, das sendet.

John Doe verwendet john.doe@gmail.com zum Senden. Sein Galeriekonto trägt dieselbe Adresse nur, wenn es wirklich sein Postfach ist. Marie Martin hat ein anderes Konto: ihre E-Mail ist marie.martin@gmail.com. Maries Link kommt bei Marie an. Zwei Konten können nicht dieselbe Adresse teilen.

Beim Anlegen ist die E-Mail Pflicht. Nach einer Änderung zeigt die Schaltfläche Speichern in derselben Zeile wie das Konto „E-Mail gespeichert.“ Laden Sie die Seite neu: die Adresse muss noch da sein. Die Schaltfläche unten auf der Seite speichert das nicht. Die automatische Ausfüllung des Browsers kann eine Adresse anzeigen, die nicht gespeichert ist.

Legen Sie außerdem einen Benutzernamen, ein Passwort mit mindestens 8 Zeichen und eine Rolle an. Sie können ein Konto entfernen.

Werkzeuge

Nur für die Verwaltung. Die Schaltfläche Werkzeuge öffnet drei Aktionen.

  • Indexieren liest die Bibliothek und bereitet die Miniaturen vor. Wählen Sie ein Jahr oder die ganze Bibliothek. Tun Sie das, bevor Sie Personen oder Szenen erkennen, und nachdem neue Fotos angekommen sind.
  • Personen erkennen: siehe Personen.
  • Szenen erkennen: siehe Szenen.

Der Fortschritt erscheint im Balken oben auf der Seite. Warten Sie das Ende ab, bevor Sie einen weiteren starten.

Lesekonto

Mit einem Lesekonto sehen Sie Fotos, Karte, Alben und ?. Sie können filtern, Fotos öffnen, die Diashow starten, an den Fernseher senden und ein Foto oder ein Video teilen.

Sie sehen nicht Personen, Szenen, Duplikate, Papierkorb, Einstellungen oder Werkzeuge. Sie können weder löschen, noch verschieben, noch exportieren, noch einen Ort ändern.
