L’application

Galerie Médias est un site que vous faites fonctionner chez vous, sur votre ordinateur. Il affiche les photos et les vidéos d’un dossier de cette machine, ou d’un disque du réseau, sans les envoyer ailleurs. Vous les retrouvez par année, mois, lieu, moment, album ou prénom. Vous les regardez en grand, en diaporama, ou sur une télé de la maison. Vous pouvez envoyer une photo ou une vidéo vers Facebook, Messenger, Instagram ou TikTok : le fichier part vers l’application, et le site reste privé. Un administrateur prépare la bibliothèque, nomme les personnes, classe les scènes, corrige un lieu, déplace ou met à la corbeille. Un compte lecture regarde, sans rien modifier.

Le programme du serveur est écrit en Python. Les pages que vous voyez sont écrites en HTML, CSS et JavaScript. La liste des photos est rangée dans SQLite, qui accompagne Python. La carte s’appuie sur Leaflet. Les visages, les scènes et les vidéos s’appuient sur d’autres programmes ouverts, notamment OpenCV, InsightFace, ONNX Runtime et FFmpeg.

Galerie Médias est publié sous la licence MIT (fichier LICENSE). Vous pouvez copier, modifier et redistribuer ce programme, y compris dans un produit payant, en conservant ce fichier et le nom de l’auteur. Les autres composants sont cités dans NOTICE.

Les bibliothèques installées avec Python gardent leur licence (MIT, BSD ou Apache 2.0). La carte utilise Leaflet 1.9.4 (BSD). Les drapeaux viennent de flag-icons (MIT). Les noms de villes viennent de GeoNames, sous Creative Commons BY 4.0. Les fonds de carte sont © OpenStreetMap contributors.

Les modèles de visages InsightFace (buffalo_l), téléchargés dans ~/.insightface/, ne sont pas sous MIT. InsightFace les réserve à la recherche non commerciale. Sans ces modèles, la détection utilise OpenCV (YuNet et SFace), sous une licence permissive. FFmpeg, pour les vidéos, est un programme séparé sous GPL. Il n’est pas inclus dans les sources de Galerie Médias.

Langue et thème

En haut à droite, deux menus restent visibles.

  • Langue : français, anglais, espagnol ou allemand. Au premier passage, le site suit la langue de votre navigateur. S’il ne la reconnaît pas, il reste en français.
  • Thème : Ambre (sombre, chaud), Encre, Océan, Forêt, Papier (clair) et Jour (clair). Ambre est le thème d’origine.

Votre choix reste dans ce navigateur, sur cet appareil. Il ne change pas le compte des autres personnes.

HTTPS et certificat

Le site s’ouvre toujours avec une adresse qui commence par https://, sur le port 8765. Il n’y a pas d’adresse en http://. Le cadenas chiffre l’échange entre votre navigateur et l’ordinateur qui fait tourner la galerie. Les photos restent sur cet ordinateur. Elles ne sont pas publiées sur Internet.

Deux cadenas sont possibles. Le premier suffit à la maison.

  • Certificat de la maison. Rien à installer. Il est créé au premier démarrage. Le navigateur affiche un avertissement une fois, parce que ce certificat n’est pas connu du public. Continuez vers le site : c’est bien votre ordinateur. Sur cet ordinateur, l’adresse est https://127.0.0.1:8765. Depuis un téléphone, sur le même Wi-Fi, elle ressemble à https://192.168.x.x:8765.
  • Certificat d’un nom. Let’s Encrypt le délivre gratuitement. Il est lié à un nom, par exemple https://photos.example.com:8765. Le navigateur ne montre plus d’avertissement. S’il est installé, il remplace le certificat de la maison. S’il manque, le certificat de la maison reste en service. L’outil qui le demande s’appelle Certbot : certbot.eff.org.

WireGuard est un VPN : un tunnel privé entre votre téléphone, ou un autre ordinateur, et la maison, quand vous n’êtes pas sur le Wi-Fi. Les installateurs pour Windows, macOS, Linux, iPhone et Android sont sur wireguard.com/install. Avec le certificat du nom, la galerie répond sur le Wi-Fi de la maison et à travers ce tunnel. Elle ne répond pas depuis un café sans le tunnel. N’ouvrez pas le port 8765 sur la box.

La télévision LG ou Samsung utilise un autre port, le 8766, sans certificat. Ce n’est pas l’adresse du site. Le bouton Télé s’en sert seulement sur le réseau de la maison.

Obtenir le certificat du nom

Cette partie est facultative. Elle prouve que le nom vous appartient, sans ouvrir de port. Le certificat suit le nom : lors d’un déménagement, changez l’adresse du nom, et gardez le même certificat.

Ces trois étapes sont les mêmes sous Linux, macOS et Windows.

  1. Réservez un nom de domaine chez Cloudflare. Laissez de côté toute offre payante de certificat, d’hébergement ou de courriel. Let’s Encrypt est gratuit.
  2. Dans le DNS du nom, ajoutez un enregistrement A. Nom : @. Adresse : celle de l’ordinateur qui fait tourner la galerie, sur le réseau de la maison (elle commence souvent par 192.168). Cliquez le nuage Cloudflare jusqu’à ce qu’il soit gris. Un nuage orange ne convient pas. Ne redirigez pas le port 8765 vers Internet.
  3. Créez un jeton sur la page des jetons Cloudflare, limité à ce nom, avec le droit de modifier le DNS. Ne le copiez ni dans un message, ni dans un document, ni dans le clavardage. Le fichier qui le contient a une seule ligne : dns_cloudflare_api_token = LE_JETON

La commande qui demande le certificat dépend du système. Remplacez photos.example.com par votre nom. La fin attendue est Successfully received certificate. Deux fichiers comptent : fullchain.pem et privkey.pem. Copiez les fichiers eux-mêmes, pas un raccourci.

Linux

Sur l’ordinateur Linux qui fait tourner le site :

sudo apt-get install certbot python3-certbot-dns-cloudflare

Enregistrez le jeton dans /etc/letsencrypt/cloudflare.ini, lisible seulement par l’administrateur (droits 600). Puis :

sudo certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials /etc/letsencrypt/cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

Copiez les deux fichiers dans le dossier de la galerie. Créez-le s’il manque. Une galerie lancée par start-linux.sh les lit dans ~/.config/galerie-photos/cache/letsencrypt/. Un service qui garde son cache dans ~/.cache/photo-library/ les lit dans ~/.cache/photo-library/letsencrypt/.

mkdir -p ~/.config/galerie-photos/cache/letsencrypt
sudo cp -L /etc/letsencrypt/live/photos.example.com/fullchain.pem ~/.config/galerie-photos/cache/letsencrypt/
sudo cp -L /etc/letsencrypt/live/photos.example.com/privkey.pem ~/.config/galerie-photos/cache/letsencrypt/

Tous les soixante jours environ, relancez la même commande Certbot et recopiez les deux fichiers.

macOS

La commande Linux ne se lance pas telle quelle dans le Terminal du Mac. Installez Homebrew, puis Certbot et le module Cloudflare :

brew install certbot
"$(brew --prefix certbot)/libexec/bin/python3" -m pip install certbot-dns-cloudflare

Créez le dossier ~/.secrets/certbot/ et le fichier cloudflare.ini avec la ligne du jeton. Dans le Terminal : chmod 600 ~/.secrets/certbot/cloudflare.ini. Puis :

sudo certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials ~/.secrets/certbot/cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

Les fichiers arrivent dans /etc/letsencrypt/live/photos.example.com/. Copiez-les vers le dossier de la galerie. Créez ce dossier s’il n’existe pas :

mkdir -p "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt"
sudo cp -L /etc/letsencrypt/live/photos.example.com/fullchain.pem "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt/"
sudo cp -L /etc/letsencrypt/live/photos.example.com/privkey.pem "$HOME/Library/Application Support/GaleriePhotos/cache/letsencrypt/"

Fermez la fenêtre de la galerie et rouvrez start-mac.command. Le certificat dure environ soixante jours. Relancez la commande Certbot, puis recopiez les deux fichiers. Le script qui renouvelle tout seul est réservé à Linux.

Windows

La commande Linux ne fonctionne pas dans la fenêtre noire de la galerie, ni dans l’invite de commandes, tant que Certbot n’est pas installé pour Windows.

Le plus simple, si un ordinateur Linux de la maison a déjà le certificat : copiez fullchain.pem et privkey.pem dans

C:\Users\VOTRENOM\AppData\Roaming\GaleriePhotos\cache\letsencrypt\

Créez le dossier letsencrypt s’il n’existe pas. Fermez la fenêtre noire, puis rouvrez la galerie.

Si la galerie tourne seulement sous Windows, installez Python depuis python.org/downloads et cochez « Add python.exe to PATH ». Ouvrez PowerShell, puis :

py -m pip install certbot certbot-dns-cloudflare

Créez un fichier, par exemple C:\Users\VOTRENOM\secrets\cloudflare.ini, avec la ligne du jeton. Puis, dans PowerShell :

py -m certbot certonly --non-interactive --agree-tos --register-unsafely-without-email --dns-cloudflare --dns-cloudflare-credentials C:\Users\VOTRENOM\secrets\cloudflare.ini --dns-cloudflare-propagation-seconds 30 -d photos.example.com

Certbot indique le dossier à la fin. Il contient les deux fichiers. Sous Windows, ce dossier est souvent C:\Certbot\live\photos.example.com\. Copiez fullchain.pem et privkey.pem dans C:\Users\VOTRENOM\AppData\Roaming\GaleriePhotos\cache\letsencrypt\, puis rouvrez la galerie. Tous les soixante jours environ, relancez la même commande Certbot et recopiez les deux fichiers.

Ouvrez ensuite https://photos.example.com:8765. Le cadenas correspond au nom. Le port reste 8765.

L’installation du programme, sous Linux, macOS et Windows, est décrite à part : Installation.

Connexion

Tant qu’aucun compte n’existe, la galerie est ouverte. Dès qu’un compte est créé, la page de connexion s’affiche.

  1. Saisissez votre identifiant.
  2. Saisissez votre mot de passe.
  3. Choisissez Se connecter.

Ce navigateur vous reconnaît ensuite pendant 14 jours. Vous n’avez pas à ressaisir le mot de passe à chaque visite, sur ce même appareil. Se déconnecter retire l’accès : les photos ne s’affichent plus tant que vous ne vous reconnectez pas.

Trois essais incorrects verrouillent le compte. Utilisez alors Mot de passe oublié, ou demandez à un administrateur de le réinitialiser.

Le premier compte créé est administrateur. Un compte lecture voit les photos, la carte, les albums et cette aide. Il ne modifie ni la bibliothèque, ni les comptes.

Mot de passe oublié

Sur la page de connexion, choisissez Mot de passe oublié.

  1. Indiquez le courriel du compte.
  2. Choisissez Envoyer le lien.
  3. Ouvrez le message. Le lien est valable une heure.
  4. Choisissez un nouveau mot de passe, de 8 caractères au minimum, puis confirmez-le.

Le site ne dit pas si le courriel existe. S’il correspond à un compte, le lien part. Après l’enregistrement, les anciennes sessions de ce compte sont fermées : il faut se reconnecter.

Le courriel saisi ici est celui du compte, dans Comptes. Ce n’est pas forcément l’adresse qui envoie les messages. Si le courriel n’est pas encore configuré, le site vous le dit. Un administrateur le prépare dans Paramètres, section Courriel, et indique le courriel de chaque compte dans Comptes. Sans cela, seul un administrateur peut choisir un nouveau mot de passe.

Photos

C’est la page d’accueil. Sans filtre, les photos les plus récentes apparaissent en premier.

Filtres

Sur un téléphone, ouvrez Filtres. Les filtres se combinent : une année et un lieu et un album, par exemple.

  • Année et Mois : d’après le dossier ou la date de la photo.
  • Lieu : une ville, une région, un pays. Moment : un voyage, un anniversaire, une fête. Un voyage n’est pas un lieu.
  • Type : photos ou vidéos.
  • Album et Scène : voir plus bas.
  • Recherche : un mot entier dans le nom du fichier, le lieu, le moment ou le prénom. « Rome » ne trouve pas « Andromède ». La croix du champ ramène toute la galerie. Il n’y a pas de menu Personne ici : tapez le prénom dans la recherche.

Changer un filtre efface la sélection en cours.

Regarder une photo

Cliquez une miniature pour l’ouvrir en grand. Le cadre respecte les proportions. Pincez l’écran, ou utilisez la molette, pour agrandir. Précédent et Suivant passent à la photo voisine. Diaporama les fait défiler.

Les vidéos se lisent dans le navigateur, y compris celles de l’iPhone.

Partager envoie la photo ou la vidéo vers Facebook, Messenger, Instagram ou TikTok. Le fichier part vers l’application : ces réseaux ne lisent pas le site. Sur un ordinateur sans liste de partage, le fichier se télécharge ; ouvrez ensuite l’application et choisissez-le.

Télévision

Télé envoie la photo ou la vidéo vers une télé LG ou Samsung allumée, sur le même réseau. Choisissez le nom de la télé, puis arrêtez-la depuis la même fenêtre quand vous avez terminé.

Sélection

Ces actions sont réservées à l’administrateur, sauf le diaporama, la télé et le partage.

  • Cette page coche les photos visibles. Tout sélectionner coche tout le filtre, pas seulement la page. Maj+clic sélectionne une plage. Effacer la sélection retire les coches.
  • L’étoile ajoute la photo à un album, ou l’en retire.
  • Ajouter à l’album et Retirer de l’album demandent au moins une photo cochée.
  • Lieu corrige le nom affiché et la pastille sur la carte. Le dossier sur le disque ne change pas. Glissez la carte : la pastille reste au centre. Vous pouvez aussi corriger les autres photos de ce seul dossier.
  • Déplacer envoie les fichiers cochés vers un dossier qui existe déjà, dans la même année. La vidéo du même nom part avec.
  • Exporter copie les originaux : l’explorateur de fichiers demande le dossier. On peut aussi télécharger une archive zip. La fenêtre se ferme à la fin. Les fichiers de la bibliothèque restent en place.
  • Supprimer envoie la sélection à la corbeille pour 30 jours, après confirmation. La limite est de 500 fichiers à la fois.

En grand format, Pivoter / rogner garde la photo modifiée dans la galerie et place l’original à la corbeille. Restaurer, dans Corbeille, remet l’original.

Cinéma

Accessible aux comptes administrateur et lecture. Cet onglet rassemble vos films, séries, documentaires et clips musicaux à partir du dossier indiqué dans Paramètres → Cinéma (par exemple /mnt/cinema).

  • Formats pris en charge : fichiers vidéo (.mp4, .m4v, .mkv, .avi, .mpg, .mov…), dossiers ou images DVD (VIDEO_TS, .iso) et Blu-ray (BDMV, .iso).
  • Lecture dans le navigateur (HLS) : la vidéo démarre en quelques secondes grâce au streaming HLS à la volée (hls.js, licence Apache 2.0), avec choix de la piste audio, des sous-titres, des chapitres, de la qualité et reprise de lecture automatique (Continuer la lecture). Raccourcis : Espace (pause), F (plein écran), flèches gauche/droite (±10 s).
  • Filtres et enrichissement Wikidata : filtrez par Type (Film, Série, Clip musical, Documentaire), Catégorie (Policier, Drame, Comédie, Thriller, Science-fiction…), Année ou recherche. Un administrateur clique Indexer Cinéma puis Enrichir (Wikidata) pour récupérer automatiquement catégories, année, réalisateur et résumé depuis Wikidata (données ouvertes CC0, sans clé API). Le bouton ✎ permet de corriger manuellement une fiche et de la verrouiller.
  • Lecteur optique physique (optionnel) : indiquez votre lecteur natif dans Paramètres → Cinéma (ex. /dev/sr0 sous Linux ou D:\ sous Windows) pour afficher le bouton Lire le disque. Laissez vide sur un serveur sans lecteur. Les disques commerciaux chiffrés (CSS/AACS/BD+) nécessitent des bibliothèques système séparées non fournies avec Galerie Médias.
  • Télévision (DLNA) : le bouton Télé dans le lecteur envoie un fichier vidéo vers une télé LG ou Samsung sur le même réseau local (port 8766). La fenêtre dit de toucher la télé pour envoyer le film. Le film est converti en H.264 720p, le format lu par la télé. La première fois, comptez 4 à 5 minutes. Le même film part ensuite tout de suite.
  • Corbeille Cinéma : un administrateur peut mettre un film ou un clip à la corbeille (bouton 🗑 sur la carte ou Supprimer dans le lecteur). Le fichier est déplacé dans .corbeille/ du dossier Cinéma pendant 30 jours et peut être restauré ou effacé définitivement depuis l’onglet Corbeille.
  • Deux index séparés : le bouton Indexer Photos (barre Outils en haut) indexe uniquement votre bibliothèque Photos (avec le sélecteur d’année ou « Toute la bibliothèque »). Le bouton Indexer Cinéma (dans l’onglet Cinéma ou Paramètres → Cinéma) indexe uniquement le dossier Cinéma.

Personnes

Réservé à l’administrateur. La reconnaissance reste sur cet ordinateur : aucun visage n’est envoyé ailleurs.

  1. Choisissez Indexer dans Outils, afin que les photos soient connues.
  2. Choisissez Détecter les personnes. La première fois peut être longue.
  3. Cochez seulement les visages que vous reconnaissez, puis nommez la sélection.
  4. Revoir place une photo de cette personne en haut. Pas… retire une erreur.

En grand format, la touche X retire le visage. Pour les photos nouvelles : indexez d’abord, puis détectez encore. Seuls les fichiers pas encore analysés sont traités.

Scènes

Réservé à l’administrateur. Une scène est une étiquette : église, montagne, ville, plage…

  1. Choisissez une année, et un lieu si vous voulez limiter le lot.
  2. Choisissez Détecter les scènes. Le résultat est une suggestion, souvent à corriger.
  3. Cochez seulement les photos justes, puis étiquetez la sélection.
  4. Revoir, puis Pas…, retire une erreur.

Dans Photos, le filtre Scène retrouve ensuite ces photos.

Doublons

Réservé à l’administrateur. La même photo peut exister dans plusieurs fichiers. Garder est une suggestion, pas une obligation.

Vous pouvez mettre à la corbeille toutes les copies en trop, ou seulement celles que vous cochez. Une confirmation s’affiche. Les fichiers restent 30 jours dans la corbeille.

Carte

Chaque pastille est un lieu. Cliquez-la pour ouvrir les photos de ce lieu. Les voyages, anniversaires et fêtes sont dans le filtre Moment, pas sur la carte.

Les fonds de carte viennent d’Internet (© OpenStreetMap contributors). Sans réseau, la carte ne s’affiche pas ; les photos, elles, restent disponibles.

Un lieu que vous avez corrigé dans Lieu reste dans le menu Lieu.

Albums

Un album est une liste. Les fichiers ne sont pas recopiés : une photo peut être dans plusieurs albums. Favoris est un album comme les autres.

  1. Saisissez un nom, puis créez l’album.
  2. Ouvrez-le, ou revenez dans Photos.
  3. Cochez des photos, puis Ajouter à l’album. L’étoile fait la même chose, et peut aussi retirer la photo.

Dans un album ouvert, Retirer de l’album enlève la sélection de cet album. Le fichier reste dans la bibliothèque.

Corbeille

Réservé à l’administrateur. Les photos supprimées restent ici 30 jours. Ensuite, le site les efface.

  • Restaurer la sélection remet les fichiers à leur place.
  • Supprimer définitivement ne concerne que les fichiers cochés, après confirmation. Cette action ne se défait pas.

Cette page, Tout et Effacer la sélection fonctionnent comme dans Photos.

Paramètres

Réservé à l’administrateur. Enregistrer, en bas de page, mémorise les réglages. Il ne lance ni le téléchargement, ni le classement, ni la sauvegarde.

Téléphone

Le site reste sur l’ordinateur qui le fait tourner. Sur le téléphone, utilisez le même réseau Wi-Fi, ouvrez l’adresse du site, puis acceptez le certificat si le navigateur le demande. Vous pouvez ensuite l’ajouter à l’écran d’accueil.

Choisissez d’où viennent les photos : iPhone / iCloud, Android / Google Photos, ou une archive Facebook / Messenger.

iCloud

Cette section télécharge les photos et les vidéos encore dans iCloud, vers le dossier de triage. Indiquez l’identifiant Apple, le mot de passe et, si besoin, l’année et le mois. Le mot de passe reste chiffré sur cet ordinateur. Le code demandé par Apple s’affiche sur l’iPhone : saisissez-le dans la page, pas dans une autre fenêtre.

Avant le premier téléchargement, ouvrez une session sur icloud.com avec le même identifiant, dans un navigateur. Apple affiche parfois ses conditions générales avant d’ouvrir les photos. Tant qu’elles ne sont pas acceptées, le téléchargement ne peut pas récupérer les photos.

Le dossier de triage est une zone d’arrivée. Ce n’est pas la galerie. Les fichiers y restent jusqu’au classement, puis jusqu’à Indexer. Exemple après un téléchargement iCloud :

triage/2024/06/IMG_1234.HEIC

Google Photos

Deux façons simples : exporter depuis Google Takeout, ou brancher le téléphone et copier le dossier DCIM. Indiquez ensuite ce dossier. Le classement se fait dans la section Classer.

Facebook

Vous pouvez télécharger les photos et les vidéos depuis Facebook. Dans Facebook : Paramètres et confidentialité, puis Vos informations, puis Télécharger vos informations. Demandez les photos, les vidéos et les messages. Le fichier message_1.json contient la date, car ces médias n’ont souvent pas de date dans la photo elle-même. Décompressez l’archive dans le dossier indiqué, enregistrez, puis lancez Classer depuis Facebook.

facebook/messages/inbox/Nom/photos/12345.jpg
facebook/messages/inbox/Nom/message_1.json

Après le classement, un fichier daté de mars 2019 se range ainsi. S’il y a une position, la ville remplace le mois :

Annee 2019/Mars 2019/12345.jpg
Annee 2019/Montreal/12345.jpg

Classer

Le classement copie les fichiers vers la bibliothèque. Si la source et la destination sont le même dossier, il les déplace. Lancez d’abord la simulation : elle n’écrit rien. Ensuite, cliquez sur Indexer pour voir les photos.

Classer année / mois range par date. Une photo prise en juin 2024, encore dans le triage, devient :

Annee 2024/Juin 2024/IMG_1234.HEIC

Classer depuis le triage lit le dossier de triage (iCloud) ou le dossier Takeout / DCIM. Classer la bibliothèque actuelle ne lit pas le triage. Il range les photos déjà dans la bibliothèque, à la racine d’une année ou dans un dossier de mois, vers un dossier de ville s’il y a une position :

Annee 2024/Rome/IMG_1234.HEIC

Sans position, le fichier reste dans le dossier du mois, par exemple Annee 2024/Juin 2024/. Les noms Annee et les mois en français sont les noms des dossiers sur le disque. Ils ne changent pas avec la langue du site.

Sauvegarde

Indiquez un dossier (disque externe, autre ordinateur), puis Sauvegarder maintenant. La copie contient l’index, les réglages et les pages du site. Les miniatures ne sont pas copiées : Indexer les recrée. Les photos elles-mêmes restent là où elles sont.

Courriel

Cette section règle le compte qui envoie le lien « mot de passe oublié ». Ce n’est pas le courriel de chaque personne. Un seul compte suffit pour toute la maison.

Exemple avec Gmail :

  • Serveur : smtp.gmail.com
  • Port : 587
  • Identifiant : john.doe@gmail.com
  • Mot de passe : un mot de passe d’application Google, 16 lettres. Google les montre en quatre blocs séparés par des espaces. Les espaces ne comptent pas : le site les retire. Ce n’est pas le mot de passe habituel du compte Google.
  • Expéditeur : john.doe@gmail.com, le même compte que l’identifiant. Une adresse inventée, par exemple galerie@gmail.com, ne part pas.
  • Chiffrement STARTTLS : coché.
  • Adresse du site : https://photos.example.com:8765, telle que les personnes l’ouvrent dans le navigateur.

Le mot de passe d’application se crée sur https://myaccount.google.com/apppasswords, après la validation en deux étapes. Choisissez « Autre » et le nom Galerie. Il reste chiffré sur cet ordinateur. Laissez le champ vide pour conserver celui déjà enregistré.

Enregistrer, en bas de la page, sauvegarde cette section. Il ne sauvegarde pas le courriel des comptes.

Comptes

Chaque personne a son propre courriel. C’est l’adresse qui reçoit le lien, et celle qu’elle saisit dans Mot de passe oublié. Elle peut être différente du compte Gmail qui envoie.

John Doe utilise john.doe@gmail.com pour l’envoi. Son compte dans la galerie porte cette même adresse seulement si c’est bien sa boîte. Marie Martin a un autre compte : son courriel est marie.martin@gmail.com. Le lien de Marie arrive chez Marie. Deux comptes ne peuvent pas partager la même adresse.

À la création, le courriel est obligatoire.
