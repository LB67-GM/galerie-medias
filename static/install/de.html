Installation

Galerie Médias, Version 4.1. Die Seite bleibt auf Ihrem Computer. Die Fotos dürfen auf einem USB-Datenträger bleiben. Die Datenbank (SQLite, Miniaturen, Einstellungen) bleibt immer auf dem Computer, nie auf dem USB-Datenträger. Die Seite hört nur auf HTTPS.

Dieselbe Anleitung gibt es auf Französisch, Englisch und Spanisch. Die Bedienung der Menüs steht in der Hilfe ?.

Wo die Dateien liegen

  • Fotos und Videos: der Ordner aus den Einstellungen. Beispiel unter Windows: E:\Photos.
  • Windows: C:\Users\IHRNAME\AppData\Roaming\GaleriePhotos\ (ouvrir-dossier-base.bat).
  • macOS: Library/Application Support/GaleriePhotos/.
  • Linux: ~/.config/galerie-photos/.

Entpacken Sie das Programm in Dokumente, nicht aus dem noch geöffneten Zip, und nicht zwingend auf den USB-Datenträger.

Windows

  1. Installieren Sie Python 3.10 oder neuer von python.org, nicht aus dem Microsoft Store. Setzen Sie das Häkchen bei Add python.exe to PATH.
  2. Entpacken Sie das Zip, zum Beispiel nach Documents\galerie-medias\.
  3. Doppelklick auf preparer-python.bat (legt .venv an, ohne die Seite zu öffnen).
  4. Doppelklick auf ouvrir-galerie.bat (oder start-windows.bat). Beim ersten Mal dauert die Installation der Pakete einige Minuten. Internet ist nötig. Wenn Windows nach der Firewall fragt, klicken Sie auf Ja. Diese Regel bleibt nach einem Neustart. Das WLAN muss ein privates Netzwerk sein.
  5. Der Browser öffnet https://127.0.0.1:8765. Beim ersten Besuch gehen Sie weiter zur Seite (Haus-Zertifikat). Ein Telefon im selben WLAN nutzt die Adresse aus dem schwarzen Fenster.

Lassen Sie das schwarze Fenster offen, solange Sie die Seite nutzen. Zum Beenden schließen Sie es. Das Fenster folgt der Windows-Sprache (Französisch, Englisch, Spanisch oder Deutsch).

  • creer-raccourci-bureau.bat — Symbol auf dem Desktop.
  • lister-disques.bat — Laufwerksbuchstabe des USB.
  • autoriser-parefeu.bat — Ports 8765 (Seite) und 8766 (Fernseher), dauerhaft.
  • reparer-installation.bat — wenn die Seite nicht mehr startet, oder nach einer neuen Version.
  • gerer-utilisateurs.bat — Konten, Passwort, Entsperren.

macOS

  1. Python 3.10 oder neuer: python.org oder brew install python.
  2. Doppelklick auf start-mac.command. Wenn macOS blockiert: Rechtsklick, dann Öffnen.
  3. Das Sitzungspasswort kann für die Firewall verlangt werden. Die Regel ist dauerhaft. Eine Ablehnung hindert nicht daran, die Seite auf diesem Computer zu öffnen. Erneut versuchen: autoriser-parefeu-mac.command.
  4. Der Browser öffnet https://127.0.0.1:8765. Gehen Sie beim ersten Besuch weiter zur Seite.

Nach einer neuen Version: reparer-installation-mac.command. Wenn das Zip über denselben Ordner entpackt wird, installiert start-mac.command die Pakete neu, sobald sich REQUIS-de.md geändert hat. Das Fenster folgt der Sprache des Mac.

Sortieren: classer-annee-mois-mac.command, danach classer-lieux-mac.command. Konten: gerer-utilisateurs-mac.command.

Linux

  1. Python 3.10 oder neuer, und python3-venv, wenn die Distribution es trennt. Debian oder Ubuntu: sudo apt-get install python3 python3-venv python3-pip. Fedora: sudo dnf install python3.
  2. Entpacken Sie das Zip, zum Beispiel nach ~/Documents/galerie-medias/.
  3. In einem Terminal, aus diesem Ordner: bash start-linux.sh.
  4. Das Skript bereitet .venv vor, versucht die Ports 8765 und 8766 zu öffnen (firewalld oder ufw) und startet dann die Seite. Wenn das Administratorpasswort abgelehnt wird, funktioniert die Seite auf diesem Computer trotzdem.
  5. Der Browser öffnet https://127.0.0.1:8765. Gehen Sie beim ersten Besuch weiter zur Seite. Ein Telefon im selben WLAN nutzt die Adresse aus dem Terminal.

Lassen Sie das Terminal offen. Zum Beenden schließen Sie es. Die Meldungen folgen LANG (Französisch, Englisch, Spanisch oder Deutsch; sonst Französisch).

HTTPS

Die Seite hat keinen HTTP-Modus. Beim ersten Start entsteht ein Haus-Zertifikat. Der Browser warnt einmal: gehen Sie weiter zur Seite.

Für einen öffentlichen Namen, zum Beispiel https://photos.example.com:8765, kommt das Zertifikat von Let’s Encrypt, nachgewiesen über DNS. An der Box wird kein Port geöffnet. Die Einzelheiten stehen in vier Sprachen in der Hilfe: HTTPS und das Zertifikat.

  1. Reservieren Sie den Namen bei Cloudflare. Zahlen Sie kein zusätzliches Zertifikat: Let’s Encrypt ist kostenlos.
  2. A-Eintrag, Name @, Adresse des Computers im Hausnetz. Cloudflare-Wolke grau. Leiten Sie Port 8765 nicht ins Internet weiter.
  3. Der Befehl, der das Zertifikat anfordert, ist unter Linux, macOS und Windows nicht derselbe. Die Schritte stehen in der Hilfe. Unter Linux kopiert ein Skript die Dateien. Unter macOS und Windows kopieren Sie fullchain.pem und privkey.pem in den Ordner letsencrypt der Einstellungen und öffnen die Galerie erneut.

Erste Verwendung

  1. Schließen Sie den Datenträger an und warten Sie, bis er erscheint.
  2. Register Einstellungen. Geben Sie den Fotoordner an, dann Speichern.
  3. Sortieren Sie vor dem Indexieren. Lose Fotos oder Fotos schon nach Jahr: classer-lieux.bat (Windows) oder classer-lieux-mac.command. Ein gemischter Baum, zum Beispiel DCIM: zuerst classer-annee-mois, dann classer-lieux. Wahl 1 simuliert, Wahl 2 schreibt. Unter Linux: .venv/bin/python tools/sort_annee_mois.py QUELLE ZIEL, dann .venv/bin/python tools/sort_lieux.py -d ZIEL. --apply schreibt.
  4. Auf der Seite: Fotos indizieren. Warten Sie das Ende ab.
  5. (Optional) Für Filme, Serien und Clips: Ordner unter Einstellungen → Kino eintragen, speichern und Kino indizieren klicken.

Die angelegten Ordner heißen Annee 2024 und Juin 2024. Diese Namen bleiben auf der Festplatte französisch.

Aktualisierung (von 4.0 auf 4.1)

Gleicher Ablauf: Seite schließen, das Zip über denselben Ordner entpacken, Datenbank und Fotos nicht anfassen, dann mit Strg+F5 neu laden. Einstellungen zeigt Galerie Médias 4.1. Nichts neu indizieren. Die Schaltfläche TV eines Films sagt, dass die erste Umwandlung 4 bis 5 Minuten dauern kann; danach startet derselbe Film sofort.

Aktualisierung (von 3.0 auf 4.0)

Schließen Sie das Fenster der Seite (oder stoppen Sie den systemd-Dienst unter Linux). Entpacken Sie das neue Zip über denselben Ordner. Löschen Sie nicht GaleriePhotos (Windows, macOS) und nicht ~/.config/galerie-photos / ~/.cache/photo-library (Linux). Kopieren oder indizieren Sie die Fotos nicht erneut: SQLite und Einstellungen migrieren automatisch auf 4.0. Danach reparer-installation.bat, reparer-installation-mac.command oder start-linux.sh / den Dienst neu starten und mit Strg+F5 neu laden. Für Kino tragen Sie den Video-Ordner unter Einstellungen → Kino ein und klicken auf Kino indizieren. Einzelheiten stehen in MISE-A-JOUR-de.md.

Wenn die Seite nicht aufgeht

  • Python nicht gefunden: python.org, PATH gesetzt, dann erneut starten.
  • Schließen Sie das alte Fenster, starten Sie erneut und öffnen Sie https://127.0.0.1:8765 von Hand.
  • Die Adresse http:// antwortet nicht: die Seite ist nur HTTPS.
  • Fotos nicht gefunden: Datenträger angeschlossen, richtiger Buchstabe (lister-disques.bat).
