Retour à la galerie

Installation

Galerie Médias, version 4.1. Le site reste sur votre ordinateur. Les photos peuvent rester sur un disque USB. La base (SQLite, miniatures, réglages) reste toujours sur l’ordinateur, jamais sur le USB. Le site n’écoute qu’en HTTPS.

La même notice existe en anglais, en espagnol et en allemand. Le mode d’emploi des menus est dans l’aide ?.

Où sont les fichiers

  • Photos et vidéos : le dossier indiqué dans Paramètres. Exemple Windows : E:\Photos.
  • Windows : C:\Users\VOTRENOM\AppData\Roaming\GaleriePhotos\ (ouvrir-dossier-base.bat).
  • macOS : Bibliothèque/Application Support/GaleriePhotos/.
  • Linux : ~/.config/galerie-photos/.

Décompressez le programme dans Documents, pas dans le zip encore ouvert, et pas obligatoirement sur le USB.

Windows

  1. Installez Python 3.10 ou plus récent depuis python.org, pas depuis le Microsoft Store. Cochez Add python.exe to PATH.
  2. Décompressez le zip, par exemple dans Documents\galerie-medias\.
  3. Double-cliquez preparer-python.bat (crée .venv sans ouvrir le site).
  4. Double-cliquez ouvrir-galerie.bat (ou start-windows.bat). La première fois, l’installation des paquets dure quelques minutes. Internet est nécessaire. Si Windows demande une autorisation pour le pare-feu, cliquez Oui. Cette règle reste après un redémarrage. Le Wi-Fi doit être un réseau Privé.
  5. Le navigateur s’ouvre sur https://127.0.0.1:8765. Premier passage : continuez vers le site (certificat de la maison). Un téléphone sur le même Wi-Fi utilise l’adresse affichée dans la fenêtre noire.

Laissez la fenêtre noire ouverte pendant l’utilisation. Pour arrêter, fermez-la. La fenêtre suit la langue de Windows (français, anglais, espagnol ou allemand).

  • creer-raccourci-bureau.bat — icône sur le Bureau.
  • lister-disques.bat — lettre du USB.
  • autoriser-parefeu.bat — ports 8765 (site) et 8766 (télé) de façon permanente.
  • reparer-installation.bat — si le site ne démarre plus, ou après une nouvelle version.
  • gerer-utilisateurs.bat — comptes, mot de passe, déverrouillage.

macOS

  1. Python 3.10 ou plus récent : python.org ou brew install python.
  2. Double-clic sur start-mac.command. Si macOS bloque : clic droit, puis Ouvrir.
  3. Le mot de passe de session peut être demandé pour le pare-feu. La règle est permanente. Refuser n’empêche pas d’ouvrir le site sur cet ordinateur. Pour réessayer : autoriser-parefeu-mac.command.
  4. Le navigateur s’ouvre sur https://127.0.0.1:8765. Continuez vers le site au premier passage.

Après une nouvelle version : reparer-installation-mac.command. Si le zip est décompressé par-dessus le même dossier, start-mac.command réinstalle aussi les paquets quand REQUIS-fr.md a changé. La fenêtre suit la langue du Mac.

Classement : classer-annee-mois-mac.command, puis classer-lieux-mac.command. Comptes : gerer-utilisateurs-mac.command.

Linux

  1. Python 3.10 ou plus récent, et python3-venv si la distribution le sépare. Debian ou Ubuntu : sudo apt-get install python3 python3-venv python3-pip. Fedora : sudo dnf install python3.
  2. Décompressez le zip, par exemple dans ~/Documents/galerie-medias/.
  3. Dans un terminal, depuis ce dossier : bash start-linux.sh.
  4. Le script prépare .venv, tente d’ouvrir les ports 8765 et 8766 (firewalld ou ufw), puis lance le site. Si le mot de passe d’administrateur est refusé, le site fonctionne quand même sur cet ordinateur.
  5. Le navigateur s’ouvre sur https://127.0.0.1:8765. Continuez vers le site au premier passage. Un téléphone sur le même Wi-Fi utilise l’adresse affichée dans le terminal.

Laissez le terminal ouvert. Pour arrêter, fermez-le. Les messages suivent LANG (français, anglais, espagnol ou allemand ; sinon français).

HTTPS

Le site n’a pas de mode HTTP. Au premier démarrage, un certificat de la maison est créé. Le navigateur avertit une fois : continuez vers le site.

Pour un nom public, par exemple https://photos.example.com:8765, le certificat vient de Let’s Encrypt, par une preuve DNS. Aucun port n’est ouvert sur la box. Le détail, dans les quatre langues, est dans l’aide : HTTPS et certificat.

  1. Réservez le nom chez Cloudflare. Ne payez pas un certificat en plus : Let’s Encrypt est gratuit.
  2. Enregistrement A, nom @, adresse de l’ordinateur sur le réseau de la maison. Nuage Cloudflare gris. Ne redirigez pas le port 8765 vers Internet.
  3. La commande qui demande le certificat n’est pas la même sous Linux, macOS et Windows. Le pas à pas est dans l’aide. Sous Linux, un script copie les fichiers. Sous macOS et Windows, copiez fullchain.pem et privkey.pem dans le dossier letsencrypt des réglages, puis rouvrez la galerie.

Première utilisation

  1. Branchez le disque et attendez qu’il apparaisse.
  2. Onglet Paramètres. Indiquez le dossier des photos, puis Enregistrer.
  3. Classez avant d’indexer. Photos en vrac ou déjà par année : classer-lieux.bat (Windows) ou classer-lieux-mac.command. Arbre disparate, par exemple DCIM : d’abord classer-annee-mois, puis classer-lieux. Le choix 1 simule, le choix 2 écrit. Sous Linux : .venv/bin/python tools/sort_annee_mois.py SOURCE DEST, puis .venv/bin/python tools/sort_lieux.py -d DEST. Ajoutez --apply pour écrire.
  4. Dans le site : Indexer Photos. Attendez la fin.
  5. (Optionnel) Pour films, séries et clips : indiquez le dossier dans Paramètres → Cinéma, enregistrez, puis cliquez Indexer Cinéma.

Les dossiers créés s’appellent Annee 2024 et Juin 2024. Ces noms restent en français sur le disque.

Mise à jour (depuis 4.0 vers 4.1)

Même geste : fermez le site, décompressez le zip par-dessus le même dossier, sans toucher à la base ni aux photos, puis rechargez avec Ctrl+F5. Paramètres affiche Galerie Médias 4.1. Rien à réindexer. Le bouton Télé d’un film prévient que la première conversion peut prendre 4 à 5 minutes ; le même film part ensuite tout de suite.

Mise à jour (depuis 3.0 vers 4.0)

Fermez la fenêtre du site (ou arrêtez le service systemd sous Linux). Décompressez le nouveau zip par-dessus le même dossier. Ne supprimez pas GaleriePhotos (Windows, macOS) ni ~/.config/galerie-photos / ~/.cache/photo-library (Linux). Ne recopiez pas les photos et ne réindexez pas la bibliothèque Photos : la base SQLite et les réglages migrent automatiquement vers la 4.0. Puis lancez reparer-installation.bat, reparer-installation-mac.command, ou relancez start-linux.sh / le service, et rechargez avec Ctrl+F5. Pour activer Cinéma, indiquez le dossier vidéo dans Paramètres → Cinéma puis cliquez Indexer Cinéma. Le détail complet est dans MISE-A-JOUR-fr.md.

Si la page ne s’ouvre pas

  • Python introuvable : python.org, case PATH, puis relancez.
  • Fermez l’ancienne fenêtre, relancez, et ouvrez https://127.0.0.1:8765 à la main.
  • L’adresse http:// ne répond pas : le site est uniquement en HTTPS.
  • Photos introuvables : disque branché, bonne lettre (lister-disques.bat).
