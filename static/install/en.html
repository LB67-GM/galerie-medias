Installation

Galerie Médias, version 4.2. The site stays on your computer. Photos may stay on a USB disk. The database (SQLite, thumbnails, settings) always stays on the computer, never on the USB disk. The site listens only on HTTPS.

The same guide exists in French, Spanish, and German. How the menus work is in the ? help.

Where the files are

  • Photos and videos: the folder set in Settings. Windows example: E:\Photos.
  • Windows: C:\Users\YOURNAME\AppData\Roaming\GaleriePhotos\ (ouvrir-dossier-base.bat).
  • macOS: Library/Application Support/GaleriePhotos/.
  • Linux: ~/.config/galerie-photos/.

Unpack the program into Documents, not from inside the still-open zip, and not necessarily onto the USB disk.

Windows

  1. Install Python 3.10 or newer from python.org, not from the Microsoft Store. Check Add python.exe to PATH.
  2. Unpack the zip, for example into Documents\galerie-medias\.
  3. Double-click preparer-python.bat (creates .venv without opening the site).
  4. Double-click ouvrir-galerie.bat (or start-windows.bat). The first time, installing the packages takes a few minutes. Internet is required. If Windows asks for the firewall, click Yes. That rule remains after a restart. Wi-Fi must be a Private network.
  5. The browser opens https://127.0.0.1:8765. On the first visit, continue to the site (home certificate). A phone on the same Wi-Fi uses the address shown in the black window.

Leave the black window open while you use the site. To stop, close it. The window follows the Windows language (French, English, Spanish, or German).

  • creer-raccourci-bureau.bat — Desktop icon.
  • lister-disques.bat — USB drive letter.
  • autoriser-parefeu.bat — ports 8765 (site) and 8766 (TV), permanent.
  • reparer-installation.bat — if the site no longer starts, or after a new version.
  • gerer-utilisateurs.bat — accounts, password, unlock.

macOS

  1. Python 3.10 or newer: python.org or brew install python.
  2. Double-click start-mac.command. If macOS blocks it: right-click, then Open.
  3. The session password may be requested for the firewall. The rule is permanent. Refusing it does not prevent opening the site on this computer. To try again: autoriser-parefeu-mac.command.
  4. The browser opens https://127.0.0.1:8765. Continue to the site on the first visit.

After a new version: reparer-installation-mac.command. If the zip is unpacked over the same folder, start-mac.command also reinstalls the packages when REQUIS-en.md has changed. The window follows the Mac language.

Sorting: classer-annee-mois-mac.command, then classer-lieux-mac.command. Accounts: gerer-utilisateurs-mac.command.

Linux

  1. Python 3.10 or newer, and python3-venv when the distribution splits it. Debian or Ubuntu: sudo apt-get install python3 python3-venv python3-pip. Fedora: sudo dnf install python3.
  2. Unpack the zip, for example into ~/Documents/galerie-medias/.
  3. In a terminal, from that folder: bash start-linux.sh.
  4. The script prepares .venv, tries to open ports 8765 and 8766 (firewalld or ufw), then starts the site. If the administrator password is refused, the site still works on this computer.
  5. The browser opens https://127.0.0.1:8765. Continue to the site on the first visit. A phone on the same Wi-Fi uses the address shown in the terminal.

Leave the terminal open. To stop, close it. Messages follow LANG (French, English, Spanish, or German; otherwise French).

HTTPS

The site has no HTTP mode. On the first start, a home certificate is created. The browser warns once: continue to the site.

For a public name, for example https://photos.example.com:8765, the certificate comes from Let’s Encrypt, proved through DNS. No port is opened on the router. The detail, in four languages, is in the help: HTTPS and the certificate.

  1. Register the name at Cloudflare. Do not pay for an extra certificate: Let’s Encrypt is free.
  2. A record, name @, address of the computer on the home network. Cloudflare cloud grey. Do not forward port 8765 to the Internet.
  3. The command that requests the certificate is not the same on Linux, macOS, and Windows. The steps are in the help. On Linux, a script copies the files. On macOS and Windows, copy fullchain.pem and privkey.pem into the settings folder letsencrypt, then open the gallery again.

First use

  1. Plug in the disk and wait until it appears.
  2. Open Settings. Set the photo folder, then Save.
  3. Sort before indexing. Loose photos, or photos already by year: classer-lieux.bat (Windows) or classer-lieux-mac.command. A mixed tree, for example DCIM: first classer-annee-mois, then classer-lieux. Choice 1 previews, choice 2 writes. On Linux: .venv/bin/python tools/sort_annee_mois.py SOURCE DEST, then .venv/bin/python tools/sort_lieux.py -d DEST. Add --apply to write.
  4. In the site: Index Photos. Wait until it finishes.
  5. (Optional) For movies, series, and clips: set the folder in Settings → Cinema, save, then click Index Cinema.

The folders created are named Annee 2024 and Juin 2024. Those names stay in French on disk.

Update (from 4.1 to 4.2)

Same steps: close the site, unpack the zip over the same folder, leave the database and the photos alone, then reload with Ctrl+F5. Settings shows Galerie Médias 4.2. Nothing to re-index. The TV button for a film says to touch the TV to send the film.

Update (from 4.0 to 4.1)

Same steps: close the site, unpack the zip over the same folder, leave the database and the photos alone, then reload with Ctrl+F5. Settings shows Galerie Médias 4.1. Nothing to re-index. The TV button for a film says the first conversion can take 4 to 5 minutes; the same film then starts right away.

Update (from 3.0 to 4.0)

Close the site window (or stop the systemd service on Linux). Unpack the new zip over the same folder. Do not delete GaleriePhotos (Windows, macOS) or ~/.config/galerie-photos / ~/.cache/photo-library (Linux). Do not copy or re-index the Photos library: SQLite and settings migrate automatically to 4.0. Then run reparer-installation.bat, reparer-installation-mac.command, or restart start-linux.sh / the service, and reload with Ctrl+F5. To enable Cinema, set your video folder in Settings → Cinema and click Index Cinema. Full details are in MISE-A-JOUR-en.md.

If the page does not open

  • Python not found: python.org, PATH checked, then start again.
  • Close the old window, start again, and open https://127.0.0.1:8765 by hand.
  • The address http:// does not answer: the site is HTTPS only.
  • Photos not found: disk plugged in, right drive letter (lister-disques.bat).
